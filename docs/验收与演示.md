# MVP 验收与演示

## 本地必测

| 操作 | 预期 |
|---|---|
| 无任何API密钥进入Mock | 能输入、播放本地声音、显示字幕、看见状态 |
| 问「你在等谁」 | 难过表情、等待朋友的回答 |
| 问「能看看照片吗」 | 好奇表情、递照片帧动画、照片卡 |
| 问「窗外的雨」 | 看窗动作、背景镜头变化 |
| 说话中按住演示 | 立即静音、清字幕和未完动作、切换倾听 |
| 松开演示按钮 | 预设雨窗问题，播放本地回答，无麦克风权限请求 |
| 快速发送多个问题 | 仅最后一轮有资格播放 |
| 打开说明→测试语音失败 | 明确错误；重试可恢复 |
| 关闭Mock，未配服务 | 显示配置/连接错误，不偷偷返回Mock |
| 聚焦文字框 | 没有输入框内层额外focus边框 |

## 真实模式必测

文字和真实语音交替至少5轮；STT、OpenRouter、TTS均有实际成功结果。说话中按住新语音并发问，旧轮迟到音频/动作不复活。拒绝麦克风权限时可改文字；断开WSS后本地停播，手动重连新建会话。

iOS Safari、Android Chrome与桌面Chrome分别检查录音编码、播放授权、20秒上限、pointercancel、切后台与输入键盘。模拟视口不能代替真机麦克风验收。

## 3–5分钟录屏脚本

- 0:00–0:30：进入场景，说明原创成年角色及输入方式。
- 0:30–1:30：文字与真实语音多轮，四状态可辨。
- 1:30–2:15：询问等待的人，展示难过；询问雨，展示看窗与镜头变化。
- 2:15–3:00：询问摄影，展示好奇、递照片帧动画与照片卡。
- 3:00–3:45：说话中开始新语音，成功打断并继续。
- 3:45–4:30：展示故障与恢复、打开Mock介绍免密钥方式。

录屏需真实捕获可运行页面，不能以剪辑字幕或静态架构图代替实际打断。当前没有最终真实链路录屏；完成部署与真机验证后再录制。
